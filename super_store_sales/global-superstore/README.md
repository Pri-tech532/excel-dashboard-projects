# 📊 Global Superstore Sales Analysis

Welcome to the **Global Superstore** project repository. This project focuses on transforming raw transactional data into a functional business dashboard using **Microsoft Excel**, marking the first milestone in my journey toward Data Science.

---

## 💡 Project Overview

This repository showcases the use of core analytical features in Excel to handle a large-scale retail dataset.
- **Data Volume:** Processed over 51,000 records.
- **Functionality:** Built an interactive dashboard using **Pivot Tables and Slicers**.
- **Visualization:** Designed custom charts to track sales, profit margins, and regional trends.
- **Objective:** Developed as a practical application of data organization and visual storytelling.

---

## 🛠️ Tools & Skills Demonstrated

* **Microsoft Excel:** Advanced formatting and dashboard layout.
* **Data Summarization:** Extensive use of Pivot Tables to aggregate complex data.
* **Interactive Design:** Using Slicers and Timelines for dynamic user filtering.
* **Reporting:** Creating meaningful Bar, Pie, and Map visualizations to highlight business KPIs.

---

## 📂 Dataset Details

* **Source:** Global Superstore (Provided for learning purposes).
* **Records:** 51,290 unique orders.
* **Coverage:** 165 countries across 5 global markets (Africa, Asia Pacific, Europe, LATAM, US).
* **Categories:** Technology, Furniture, and Office Supplies.

---

## 📂 Repository Organization

This repository is structured into modular sub-folders. Each folder represents a specific business analysis and follows a standardized layout to ensure data integrity and easy navigation:

* **📁 [Module Name]/**: Each analysis is contained in its own directory.
    * **`README.md`**: Provides specific business insights, KPIs, and technical documentation for that module.
    * **`*.xlsx`**: The interactive Excel dashboard and processed data.
    * **`*.png`**: High-resolution image previews for immediate visual reference.

*To explore a specific analysis, please navigate into the respective folders listed above.*
