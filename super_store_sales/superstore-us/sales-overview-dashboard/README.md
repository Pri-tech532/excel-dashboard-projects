# 📊 Sales Overview Dashboard | Superstore Analysis

![Dashboard Preview](sales-dashboard.png)

This project presents a comprehensive **Sales Overview Dashboard** built using Excel, focusing on key business metrics and performance insights from the Superstore dataset.

---

## 💡 Project Objective

To analyze overall sales performance and extract meaningful insights related to revenue, customer behavior, and product categories.

---

## 📁 Project Structure

* 📄 `superstore-sales-data.xlsx` → Dataset and dashboard
* 🖼️ `sales-dashboard.png` → Dashboard preview
* 📘 `README.md` → Project documentation

---

## 📊 Key Performance Indicators (KPIs)

* Total Sales
* Total Orders
* Total Customers
* Average Order Value

---

## 📈 Dashboard Features

* Year-wise filtering using slicers
* Category-wise sales distribution (Technology, Furniture, Office Supplies)
* Region/State-wise sales visualization
* Monthly sales trend analysis
* Product category performance comparison

---

## 🔍 Key Insights

* Technology category contributes the highest share of total sales, indicating strong demand
* Sales fluctuate across months, suggesting seasonal trends
* Certain regions generate higher sales volumes, highlighting geographical demand differences
* Average order value indicates consistent mid-range purchasing behavior
