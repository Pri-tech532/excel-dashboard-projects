# 📊 US Superstore Sales Analysis

Welcome to the **US Superstore** project repository. This project focuses on transforming raw retail data into an interactive business dashboard using **Microsoft Excel**, strengthening my foundation in Data Analytics.

---

## 💡 Project Overview

This repository demonstrates the application of core analytical techniques in Excel to analyze a retail dataset and generate meaningful business insights.

* **Data Handling:** Worked with structured transactional sales data
* **Functionality:** Built an interactive dashboard using **Pivot Tables and Slicers**
* **Visualization:** Designed charts to analyze sales trends, product performance, and regional distribution
* **Objective:** To practice data analysis, visualization, and storytelling using real-world business data

---

## 🛠️ Tools & Skills Demonstrated

* **Microsoft Excel:** Dashboard design and data formatting
* **Data Analysis:** Use of Pivot Tables for summarization
* **Interactive Reporting:** Slicers for dynamic filtering
* **Visualization:** Bar charts, pie charts, and trend analysis

---

## 📂 Dataset Details

* **Source:** Kaggle – Superstore Dataset
* **Scope:** Retail sales data across different regions in the United States
* **Categories:** Technology, Furniture, and Office Supplies
* **Data Includes:** Orders, customers, sales, profit, and regional information
